The command line

And now you will finally get to work with a terminal on your own computer, yay!

1. Get a terminal

You need a terminal that runs the Bash shell, and the exercise data.

  • macOS
  • Windows
  • Linux

Terminal is already installed. Open it with Spotlight (Cmd + Space, type Terminal) or from Applications → Utilities → Terminal.

Newer Macs start the zsh shell, not Bash. Check which one you have:

echo $SHELL

If it says /bin/zsh, type bash and press Enter each time you open the terminal. Most commands work the same in both shells, but this way your terminal matches the exercises.

To get a terminal with a linux shell, install the Windows Subsystem for Linux (WSL). Follow the instructions in the link above.

Very short summary:

  • type in the bottom left search bar “powershell”, right-click on the result and select “run as administrator”
  • copy-paste in the window you opened the following command:
wsl --install
  • reboot your system
  • launch WSL (the first time will take a while), set a username and a password (you will be prompted autmatically)
NoteUsing WSL (Ubuntu on Windows)?

Your Windows Desktop is at /mnt/c/Users/<your Windows name>/Desktop, not at ~/Desktop. Adjust the paths in the exercises.

Open the Terminal app. It runs Bash by default.

Download the exercise data

  1. Download shell-lesson-data.zip.
  2. Move it to your Desktop.
  3. Unzip it there, so that you have a folder shell-lesson-data on your Desktop. On Windows, right-click the zip and choose Extract All…. Double-clicking can create a folder inside a folder with the same name.

Check that it works

Open the terminal and type:

cd
ls Desktop/shell-lesson-data

You should see exercise-data and north-pacific-gyre. If you get No such file or directory, ask a teacher.

2. Exercises

We follow the Software Carpentry lesson The Unix Shell. The data is the zip you downloaded above, so you can skip the lesson’s own setup page.

ImportantTo do for you

Work through these episodes. Type every command yourself, do not copy and paste. Do the challenges and only then open the solutions.

  1. Introducing the Shell
  2. Navigating Files and Directories
  3. Working With Files and Directories
  4. Pipes and Filters

Skip the sections about Nelle (“Nelle’s Pipeline: …”). They come at the end of the episodes.

TipPay extra attention to
  • Paths. Before each command, ask yourself: where am I (pwd), and where is the file I want? Most errors on the server later are a wrong path.
  • nano and touch in episode 3. You will write your own scripts with nano on the server. Do the challenge Creating Files a Different Way, which uses touch.
  • rm is permanent. There is no bin to get files back from.

Bonus

  • If you finish early, try your hand at Shell Scripts: save commands in a file and run them. On the server, every job you submit is a script like this. Skip the Nelle section. Some challenges use loops from episode 5; you can skip those.
NoteNeed a reminder?

The Carpentries reference page lists all commands from the lesson. explainshell.com explains any command you paste into it.

3. Discussion

We will talk about these questions in class.

  1. You type cd data and get No such file or directory, but you are sure the folder exists. What could be wrong, and which commands help you find out?
  2. When would you use an absolute path, and when a relative one? Which one still works if you move your project folder?
  3. Why do many bioinformaticians avoid spaces in file and folder names?
  4. What can you do in the terminal that is hard to do by clicking in a file browser? And the other way round?
